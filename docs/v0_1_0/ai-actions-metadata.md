# 🧠 AI Grounding & Metadata Guide

**Version:** 0.1.0  
**Context:** Generative AI, Google Search Grounding, and Citations Metadata

When executing AI Actions configured with Google Search grounding enabled (e.g. with `gemini-2.5-flash` or `gemini-2.5-flash-lite`), ApexKit captures the citations, search queries, and reference metadata produced during inference.

This data is attached directly to the `metadata` property of the response object.

---

## 1. The Response & Metadata Structure

When invoking an action via `POST /api/v1/ai/run/{slug}`, the server returns a structured response:

```json
{
  "result": "ApexKit is an all-in-one Backend-as-a-Service built in Rust with embedded SQLite, Tantivy search, and QuickJS...",
  "metadata": {
    "webSearchQueries": [
      "ApexKit BaaS features",
      "Rust SQLite backend architecture"
    ],
    "groundingChunks": [
      {
        "web": {
          "title": "ApexKit Official Documentation",
          "uri": "https://apexkit.dev/docs"
        }
      },
      {
        "web": {
          "title": "GitHub - apexkit",
          "uri": "https://github.com/apexkit/apexkit"
        }
      }
    ],
    "groundingSupports": [
      {
        "groundingChunkIndices": [0, 1],
        "segment": {
          "startIndex": 0,
          "endIndex": 98,
          "text": "ApexKit is an all-in-one Backend-as-a-Service built in Rust with embedded SQLite..."
        }
      }
    ]
  }
}
```

### Metadata Fields
* **`webSearchQueries`**: Exact search queries generated by the model to research the prompt.
* **`groundingChunks`**: The web pages and resources referenced by the model, containing their title and destination URL.
* **`groundingSupports`**: Character offsets linking specific segments of generated text to their corresponding source chunk indices.

## 2. Use Case: Automated Content Generation & Keyword Tagging

Because `webSearchQueries` reflects the exact queries the model ran to research the topic, they serve as high-relevance SEO keywords and tags.

### Server-Side Edge Script (QuickJS / TypeScript)

You can call an AI Action from an internal script or webhook using the native global `fetch()` with relative paths:

```typescript
// Script: generate-blog-post
// Trigger: manual | Path: ./webhooks/generate-blog-post.ts

export default async function (req: Request) {
    const { topic } = await req.json();

    if (!topic) {
        return new Response({ error: "Missing 'topic' in request body" }, { status: 400 });
    }

    // 1. Invoke the AI Action using the built-in relative fetch API
    const aiResponse = await fetch("/api/v1/ai/run/content-editor", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
            variables: {
                prompt: `Write an informative overview of ${topic}.`,
                originalText: ""
            }
        })
    });

    if (!aiResponse.ok) {
        const errorText = await aiResponse.text();
        return new Response({ error: `AI Action failed: ${errorText}` }, { status: 500 });
    }

    const { result: articleContent, metadata } = await aiResponse.json();

    // 2. Extract and deduplicate search queries to use as SEO tags
    const rawQueries: string[] = metadata?.webSearchQueries || [];
    const seoTags = [...new Set(rawQueries)].slice(0, 5);

    // 3. Persist to database using $db
    const { id: newPostId } = await $db.records.create("posts", {
        title: topic,
        content: articleContent,
        tags: seoTags,
        status: "draft"
    });

    return new Response({
        success: true,
        post_id: newPostId,
        tags: seoTags,
        sources: metadata?.groundingChunks || []
    }, { status: 201 });
}
```

## 3. Use Case: Frontend Citations & Footnotes

You can display citations alongside the generated content to show verification sources.

### Frontend Example (React / TypeScript SDK)

```tsx
import React, { useState } from 'react';
import { ApexKit } from '@apexkit/sdk';

const apex = new ApexKit('https://api.your-app.com');

interface SourceChunk {
  web?: {
    title: string;
    uri: string;
  };
}

export function ResearchAssistant() {
  const [text, setText] = useState('');
  const [sources, setSources] = useState<SourceChunk[]>([]);
  const [loading, setLoading] = useState(false);

  const handleResearch = async (topic: string) => {
    setLoading(true);
    try {
      const response = await apex.ai.run('content-editor', {
        prompt: `Explain recent advances in ${topic}`,
        originalText: ''
      });

      setText(response.result);
      setSources(response.metadata?.groundingChunks || []);
    } catch (err) {
      console.error('Inference error:', err);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="max-w-2xl mx-auto p-6 space-y-6">
      <button 
        onClick={() => handleResearch('Quantum Computing')} 
        disabled={loading}
        className="px-4 py-2 bg-indigo-600 text-white rounded hover:bg-indigo-700"
      >
        {loading ? 'Researching...' : 'Generate Article'}
      </button>

      {text && (
        <article className="prose dark:prose-invert">
          <p className="whitespace-pre-wrap">{text}</p>
        </article>
      )}

      {sources.length > 0 && (
        <footer className="pt-4 border-t border-slate-700 text-sm">
          <h4 className="font-semibold text-slate-300">Sources & Grounding Citations:</h4>
          <ul className="list-disc pl-5 space-x-2 mt-2">
            {sources.map((chunk, idx) => (
              chunk.web && (
                <li key={idx}>
                  <a 
                    href={chunk.web.uri} 
                    target="_blank" 
                    rel="noopener noreferrer" 
                    className="text-blue-400 hover:underline"
                  >
                    [{idx + 1}] {chunk.web.title || chunk.web.uri}
                  </a>
                </li>
              )
            ))}
          </ul>
        </footer>
      )}
    </div>
  );
}
```

## 4. Enabling Google Search Grounding

Search grounding is supported on Gemini models (such as `gemini-2.5-flash` or `gemini-2.5-flash-lite`).

1. Open the **Admin Dashboard > AI Actions**.
2. Create or edit an action.
3. Select a supported model (`gemini-2.5-flash` recommended).
4. In the action JSON config, enable `grounding`:
   ```json
   {
     "provider": "gemini",
     "grounding": true
   }
   ```
5. Save the Action. Any subsequent calls to `/api/v1/ai/run/{slug}` will execute with Google Search integration and populate the `metadata` payload.
